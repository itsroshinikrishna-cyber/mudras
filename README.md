# मुद्रा — Mudra Compendium

An illustrated online reference of sacred Indian hand gestures — mudras — across yoga, classical dance, martial arts, music, chakras, and ancient symbols. Fully self-contained, zero dependencies beyond Google Fonts.

## Pages

| File | Content |
|------|---------|
| `index.html` | Catalog of 13 mudras + About Mudras |
| `chakras.html` | Mudras & the Seven Chakras |
| `symbols.html` | Sacred Symbols (Sri Yantra, bija mantras, trishula, bindu…) |
| `martial.html` | Mudras in Indian Martial Arts (Kalaripayattu, Varma Kalai, Silambam, Gatka, Thang-Ta, Chhau…) |
| `music-dance.html` | Mudras in Music & Dance (Carnatic tala, composer signatures, Kathak, Sattriya, Kutiyattam, Yakshagana, Theyyam…) |
| `sources.html` | All references & ancient texts |

## Deploy to Vercel

1. Push this folder to a GitHub repo
2. [vercel.com](https://vercel.com) → sign in with GitHub → Add New Project → import repo
3. Leave all settings default → Deploy
4. Live in ~20 seconds ✓
