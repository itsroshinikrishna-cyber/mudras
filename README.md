# मुद्रा — Mudra Compendium

An illustrated online reference of sacred Indian hand gestures across classical dance, yoga, Buddhist iconography, the seven chakras, and ancient Indian symbols.

## Deploy to Vercel (easiest way)

1. Push this folder to a GitHub repo
2. Go to [vercel.com](https://vercel.com) → sign in with GitHub
3. Click **Add New Project** → import your repo
4. Leave all settings as default → click **Deploy**
5. Live in ~20 seconds ✓

## Pages

| File | Page |
|------|------|
| `index.html` | Catalog of 13 mudras + About Mudras |
| `about.html` | About Mudras (standalone) |
| `chakras.html` | Mudras & the Seven Chakras |
| `symbols.html` | Sacred Symbols (yantras, bija mantras, glyphs) |
| `sources.html` | Sources & Texts |

All files are fully self-contained — no external dependencies except Google Fonts.
